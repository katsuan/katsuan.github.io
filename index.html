ツール

backup_and_delete.bat

Windows用の補助ツールです。ファイルやフォルダをこの .bat の アイコンにドラッグ&ドロップすると、同じ階層の backup フォルダにコピーしてから元のファイル/フォルダを削除します。

ダウンロード

ブックマークレット: 下のボタンをブックマークバーにドラッグ&ドロップして登録してください(クリックはこのページ上では動作しません)。

Markdownリンクをコピー

MD Link Copy

JSONを整形表示

APIレスポンスなど、プレーンなJSONだけが表示されているページを見やすく整形します。

JSON Pretty

URL末尾のIDをコピー

LIFF ID・チャンネルIDなど、コンソール画面のURL末尾に出ているIDをコピーします。

Copy Last ID

フェイクターミナル

画面いっぱいに、ビルドログが流れ続ける偽のターミナルを表示します。Escキーで閉じられます。

OGP/メタ情報チェッカー

文字数カウンター
